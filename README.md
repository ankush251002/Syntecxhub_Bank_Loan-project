🏦 Bank Loan Analysis — Risk Assessment & Predictive Modeling📌 Project OverviewFinancial institutions face significant capital risk from loan defaults. This end-to-end data analytics and machine learning project analyzes 38,576 historical bank loan applications from 2021 across the United States to identify key drivers of loan defaults, predict repayment outcomes, and provide an interactive Power BI dashboard for real-time executive risk monitoring.🎯 Primary ObjectivesData Cleaning & Feature Engineering: Standardize raw loan records, handle missing values, and engineer temporal and risk-segmentation features.SQL-Driven KPI Aggregation: Compute portfolio-level performance metrics and Good vs. Bad loan distributions using DuckDB.Exploratory & Multivariate Analysis: Uncover high-risk borrower profiles and compounding default factors.Predictive Modeling: Build classification and regression models to evaluate feature importance and predict total payment outcomes.Interactive BI Dashboarding: Deliver a multi-page Power BI dashboard enabling scenario filtering and loan-level drill-through.📂 Repository StructureBank-Loan-Analysis/
